# PomiTranslate assets

These are the files the README and the local web UI use. The product name is PomiTranslate. The subtitle is World Translator for Minecraft. The mascot is Pomi.

The app icon master is direction A.

- `icons/app/icon_app_master_v1.icns`
- `icons/app/icon_app_master_v1.ico`
- `icons/app/icon_app_direction_a_v1_rounded.png`
- `brand/wordmark/logo_wordmark_v1.png`
- `mascot/base/mascot_base_front_v1_512.png`
- `illustrations/docs/` for scan, backup, API notice, and unsupported formats. The unsuffixed cards are Korean. `_en`, `_ja`, and `_zh` are the same pictures with that language's wording. The wordmark stays in the product name for every language.
- `icons/feature/` for the features the current translator actually has

The larger generated set, including every size and seasonal pose, stays outside this repository.
