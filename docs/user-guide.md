# PomiTranslate 사용 안내

## 시작 전

현재는 개발 중인 앱입니다. macOS Apple Silicon의 개발 앱에서 주요 흐름을 확인했지만 정식 서명 배포·전체 OS 검증은 완료되지 않았습니다. [실행 준비](development.md)와 [지원 범위](support-matrix.md)를 먼저 확인하세요.

Minecraft나 서버를 종료하고 월드의 **독립된 복사본**을 만드세요. 자동 백업은 별도 백업을 대체하지 않습니다. 원본 맵·리소스팩의 권한은 그대로 원작자에게 있으며 MIT 소프트웨어 라이선스가 맵 재배포 권한을 부여하지 않습니다.

## 1. 환경 설정

- **제공사·모델:** 본인의 API 계정에서 사용할 수 있는 모델 ID를 지정합니다. Custom은 endpoint와 wire format을 함께 확인합니다.
- **API 키:** AI 번역 때 본인의 키를 입력하고 저장합니다. 저장된 키는 값 대신 저장 여부만 보여 줍니다. 변경·삭제와 키 관리 영역을 제공합니다.
- **추론(OpenRouter):** 모델 기본값, 추론 끄기, 직접 설정 중 선택합니다. 모델 정보가 확인된 경우 지원 강도만 표시합니다. 필수 추론 모델에서는 끄기를 선택할 수 없습니다.
- **모델 정보 조회:** OpenRouter는 공개 catalog를 자동 조회하며 수동 새로고침도 제공합니다. 이 조회는 설정을 저장하지 않습니다. 다른 제공사는 저장된 키가 필요할 수 있습니다. 캐시·조회 실패·모델 미발견은 화면에 구분해 표시합니다.
- **언어·문체:** 도착 언어, 문체 preset, 추가 지시를 설정합니다. UI 언어(ko/en/ja)는 번역 언어와 별개입니다.
- **범위·ZIP:** 필요한 텍스트 종류와 월드 내장 또는 명시적으로 선택한 외부 ZIP을 설정합니다. 범위가 바뀌면 다시 스캔합니다.
- **하단 저장:** 변경됨/저장됨 상태를 확인하고 저장하거나 변경 취소합니다. 가져오기·내보내기는 공개 설정용이며 키는 포함하지 않습니다.

`번역 지시문 다듬기`는 제공사에 요청하는 AI 기능이며 별도 비용이 발생할 수 있습니다. 확인 후 실행하세요. OpenRouter 사용량 확인은 저장된 키의 누적 사용량 조회이며 이 작업의 비용만 분리한 값은 아닙니다.

## 2. 월드 선택과 스캔

복사본의 월드 폴더를 선택하고 호환성 경고를 확인합니다. **월드 스캔**은 번역 API 호출·월드 파일 수정 없이 후보를 수집합니다. 앱 데이터에는 scan plan과 보고서가 기록될 수 있습니다.

스캔 결과에서 고유 문자열 수와 등장 위치 수를 구분해 읽습니다. 스캔 대상과 스캔 제외 목록도 확인하세요. 모르는 포맷·압축·읽기 오류를 지원 완료로 간주하지 않습니다.

## 3. 후보 검토

검색·텍스트 유형·상태 필터로 문장을 찾습니다. 항목을 선택하면 원문과 등장 위치를 확인하고 직접 번역문을 입력할 수 있습니다. 포함을 해제하면 해당 후보를 번역에서 제외합니다.

현재 후보는 같은 원문을 여러 등장 위치에 적용하는 단위입니다. 위치별 번역 분리, glossary와 translation memory는 후속 작업입니다. 모든 문장을 직접 번역하면 AI 번역 API 요청 없이 적용할 수 있습니다.

## 4. 실행과 결과

**번역 진행**에서 대상 월드, 언어, 모델, 추론 방식, 요청 수·비용 추정과 외부 전송 안내를 확인합니다. 추정은 청구 상한이 아닙니다. 추론 토큰·재시도·계정/라우팅 차이와 제공사 집계 지연을 고려해 실제 대시보드도 확인하세요.

실행 중 취소를 요청하면 협력적으로 중단하며 checkpoint를 사용해 남은 번역을 이어갈 수 있습니다. 취소·실패가 항상 파일 변경0을 뜻하지 않으므로 완료 결과의 변경 수·오류·사용량을 확인합니다. 이미 기록한 파일이 있으면 백업 복원을 검토하세요. 재개 설정이나 파일 지문이 달라지면 재스캔이 필요할 수 있습니다.

결과의 상태·오류·경고를 보고 게임에서 내용과 명령 동작을 직접 확인합니다. 번역문은 부정확할 수 있습니다. 보고서 내보내기에는 경로·원문·번역문이 포함될 수 있으므로 공유 전에 확인하세요.

## 5. 복원

Minecraft와 서버를 종료한 상태에서 **백업 관리**를 엽니다. 월드와 복원 시점을 확인하고 복원 안내를 읽은 뒤 실행합니다. 복원 직전 현재 파일을 보관하는 recovery snapshot이 생성됩니다. 복원은 해당 파일의 백업 이후 편집·게임 진행을 되돌릴 수 있습니다.

검증되지 않은 백업·경로 오류·손상 경고를 무시하지 마세요. 백업은 모든 저장장치 고장이나 외부 수정에서 복구를 보장하지 않습니다.

## CLI

CLI는 같은 Python 코어를 사용하며 데스크톱 vault와 credential 경로가 다릅니다. 기존 CLI의 keyring/환경변수 호환을 유지합니다. 비밀을 명령 인자·평문 설정·Git에 기록하지 말고 기존 OS keyring을 사용하세요. 데스크톱에 키를 저장했다고 CLI에서 자동 공유되는 것은 아닙니다.

```bash
# --report-path는 월드 밖의 임시 경로로 지정합니다.
.venv/bin/python mc_world_translator.py \
  --world-dir "/path/to/World-copy" \
  --dry-run \
  --report-path "/tmp/pomi-scan-report.json"

.venv/bin/python mc_world_translator.py --help
```

macOS/Linux 예시이며 Windows에서는 `.venv\Scripts\python.exe`를 사용합니다. 번역 명령에는 `--target-language`, `--provider`, `--model`, `--style-preset`, `--expect-fingerprint` 등이 있습니다. fingerprint는 스캔 보고서에서 확인한 값을 사용하며, 실제 실행은 파일 수정과 API 청구를 발생시킬 수 있습니다. CLI의 `--restore-backup`은 검증된 최신 백업 복원입니다.

문제가 있으면 [Issues](https://github.com/kim0040/Minecraft-World-Translator/issues)에 OS·버전·비밀을 제거한 재현 절차를 남겨 주세요. [면책 안내](disclaimer.md) · [데이터 안내](privacy.md)
