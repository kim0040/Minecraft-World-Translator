## What Users Should Check

- Close the game/server and prepare a separate world copy and an independent backup. Automatic backups and atomic file writes do not guarantee recovery from every incident.
- Check the supported scan scope and warnings. Processing an unverified version or mod should not be interpreted as confirmed support.
- Check for failures or partial changes in the result, then verify translations and command behavior in the game. Cancellation or an error does not mean that zero files were changed.
- Check your API account, charges, data-transfer scope, and privacy policies, and protect your key. External API costs may apply even though the app is free.
