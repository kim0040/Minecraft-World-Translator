# PomiTranslate

**World Translator for Minecraft** — Minecraft Java Edition のワールド内テキストを翻訳するデスクトップアプリ

<img src="../assets/brand/wordmark/logo_wordmark_v1.png" alt="PomiTranslate" width="340" />

[한국어](../README.md) | [English](README.en.md) | 日本語 | [简体中文](README.zh.md)

海外のアドベンチャーマップを遊んでいると、看板や本、アイテム説明が読めずに手が止まることがあります。PomiTranslate は、そんなテキストを読みたい言語に変えるデスクトップアプリです。まずワールドをスキャンして翻訳する文を確認し、必要な文だけを選んで自分で訳すか、選んだ AI プロバイダーに任せて翻訳し、検証済みのバックアップとともにワールドへ適用します。

大学生の **김현민（Hyunmin Kim）** が自分のために作り始めた無料の個人オープンソースプロジェクトです。個人の時間と限られた予算で開発しており、企業が運営する商用サービスや有料サポート製品ではありません。マスコットは **Pomi** です。

## 動作の流れ

PomiTranslate はワールドをアプリ内にコピーせず、選択したフォルダーを直接読み取ります。作業は 5 つの段階に分かれており、スキャンとレビューの段階ではワールドファイルが一切変更されません。

1. **ワールド選択** — Java Edition のワールドフォルダー（level.dat を含む）またはサーバーのルートフォルダーを開きます。検出したディメンション、データ形式（DataVersion）、ワールド内蔵リソースパック、保存中のバックアップ数を表示します。Bedrock、旧形式の `.mcr`、`.linear`、ゲームやサーバーが使用中のワールドは開始前にブロックします。
2. **スキャン** — 翻訳すべき文を探します。この段階では翻訳 API を呼び出さず、ワールドファイルも書き換えません。固有の文字列数、出現位置の総数、予想 API リクエスト数、テキストの種類をまとめ、読めないチャンクや未対応形式は元のまま残して警告として知らせます。
3. **レビュー** — 検索、並べ替え、種類・状態フィルターで候補を確認します。翻訳したくない文を除外し、任意の文には自分の訳文を入力できます。同じ原文が複数の場所で使われている場合は 1 回だけ翻訳し、すべての場所に適用します。
4. **実行** — 対象ワールド、翻訳先言語、プロバイダーとモデル、送信する文字列数、予想リクエスト数と費用、安全バックアップの有無を確認してから開始します。すべての翻訳が正常に終わるまで、ワールドの元ファイルは変更されません。
5. **結果と復元** — 変更されたファイル数、翻訳・失敗・原文維持の文、使用トークンと実際の請求費用を確認します。元に戻したいときはバックアップ管理から任意の時点へ復元します。復元直前の状態も安全スナップショットとして残ります。

## 主な機能

### スキャンとレビュー

- ワールドを変更したり翻訳 API を呼び出したりせずに、候補と対応範囲を先に確認できます。
- 検索、並べ替え（ワールド順・原文順・出現頻度順・種類別）、種類・状態フィルター、一括の対象化/除外を提供します。
- 文ごとの出現位置を確認し、自分の訳文を入力できます。手動翻訳だけを適用する場合、翻訳 API リクエストは不要です。
- すでに翻訳先言語で書かれたテキストをスキップし、再翻訳の費用を抑えられます。

### プロバイダーとモデル

- OpenAI、Gemini、Anthropic、OpenRouter、Comet、Custom endpoint（OpenAI/Anthropic 互換の通信形式）を設定できます。利用できるモデルはプロバイダーとアカウントによって異なります。
- モデル一覧を取得し、単価情報があれば 100 万トークンあたりの価格を表示します。OpenRouter は公開カタログを自動で取得し、この取得は設定を保存しません。
- OpenRouter の推論はモデル既定、オフ、対応する強度の指定から選びます。オフにできないモデルや未対応の強度は保存できません。
- 翻訳先言語と文体（標準・親しみやすい・格式・丁寧・物語風・カスタムシステムプロンプト）を設定し、追加の指示を加えられます。指示文の推敲は別の AI リクエストのため、費用が発生することがあります。

### 安全な書き込みと復元

- 書き込み前に変更対象のファイルを検証済みバックアップとして保管し、復元直前の状態も recovery snapshot として残します。
- スキャン後にワールドが変わるとフィンガープリントが一致せず、書き込みを拒否します。ゲームやサーバーがワールドを使用中の場合は session.lock の衝突で書き込みを中止します。
- ワールド外を指すパスやシンボリックリンクのリソースパックは、読み取りと API 送信の前にブロックします。
- キャンセルや失敗のときも翻訳済みの文は保存され、残りの文だけを続けて翻訳できます。プロバイダー障害で失敗した場合、ワールドファイルはまったく変更されません。
- 読めないチャンクは元のまま保持し、結果で報告します。

### リソースパック ZIP

- オプションで、ワールド内の `resources.zip` と明示的に選択した外部 ZIP（最大 16 個）の言語ファイルを処理します。
- 外部 ZIP も変更前にバックアップし、復元時は設定で同じ ZIP を選び直す必要があります。フォルダー形式のパックはまだ対応していません。

### キーとプライバシー

- API キーの既定の保存方式は **ローカル暗号化 SQLite + 別の key ファイル** です。セッション専用と OS キーチェーンは任意です。
- 保存済みのキーは画面に再表示せず、公開設定 JSON やワールドバックアップにも含まれません。
- OS キーチェーンへはユーザーが取り込みボタンを押したときだけアクセスし、アプリ起動時に自動で読み取りません。

### デスクトップ体験

- Tauri 2 + Svelte 5 の画面と Python コアを使用し、UI 用の localhost サーバーは開きません。
- UI 言語は韓国語・英語・日本語で、システム・ライト・ダークテーマに対応します。表示メニューから 75–200% の拡大ができます。
- 同じコアを使う CLI も同梱しています。デスクトップに保存したキーと CLI の keyring/環境変数は自動では共有されません。

## 使い方

1. Minecraft またはサーバーを終了し、**ワールドの独立したコピー**を作ります。
2. **環境設定**でプロバイダー、モデル、翻訳先言語と必要な翻訳指示を設定します。AI 翻訳を使う場合は自分の API キーを入力して保存します。
3. **ワールド選択 → ワールドスキャン**でコピーを選び、対応範囲と警告を確認します。
4. **候補レビュー**で除外する文と手動翻訳を指定します。
5. **翻訳の実行**で対象・推論・外部送信・予想費用を確認してから開始します。
6. **完了結果**を確認し、ゲーム内で内容を確かめます。元に戻すには **バックアップ管理** から復元します。

費用の見積もりは実際の請求額と異なることがあります。推論トークン、再試行、モデルルーティングの費用は見積もりに含まれないため、プロバイダーのダッシュボードも確認してください。設定・復元・CLI の詳細は [使用ガイド](user-guide.md) にあります。

### 実行・インストール

現在は開発ビルドを基準に案内しています。署名済みの正式インストーラーやすべての OS 対応が完了したとは案内しません。ソースからの実行には Python 3.12、Node.js 22.12 以上、pnpm 12.6.0、Rust toolchain と [Tauri のプラットフォーム準備](https://v2.tauri.app/start/prerequisites/) が必要です。

```bash
git clone https://github.com/kim0040/PomiTranslate.git
cd PomiTranslate
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt pyinstaller==6.16.0
pnpm install --frozen-lockfile
pnpm desktop:dev
```

上記の仮想環境の有効化は macOS/Linux の例です。Windows のコマンド、toolchain のバージョン、パッケージングは [開発ガイド](development.md) を、貢献の手順は [CONTRIBUTING.md](../CONTRIBUTING.md) を参照してください。完成したパッケージは Python sidecar を含む構成ですが、clean-machine でのインストール検証はまだ残っています。

## 対応範囲

看板、本のページとタイトル（フィルタリングされたタイトルを含む）、エンティティ・ブロック名、アイテム名と説明、テキストディスプレイ、コマンドテキストコンポーネント、ZIP リソースパックの言語ファイルを処理します。圧縮は gzip、zlib、無圧縮、LZ4、外部 `.mcc` を検証済みです。検証済みの **合成形式** が基準であり、すべての Minecraft バージョン・MOD・ワールドのテキストを見つけるという意味ではありません。

スキャン対象は各ディメンションの `region`/`entities` フォルダー、ワールド内の `resources.zip`、デスクトップで明示的に選択した外部 ZIP です。データパック、scoreboard、command storage、`level.dat` のテキスト、playerdata、フォルダー形式のリソースパックは現在の範囲に含まれません。Bedrock、`.mcr`、`.linear`、未知の圧縮には書き込みません。[対応表](support-matrix.md)
